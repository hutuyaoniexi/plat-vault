# PlatVault v0.3.0

## 版本定位

PlatVault v0.3.0 是 Chrome Manifest V3 扩展，包含仓库估价、核桃分析和紫卡截图分析三个模块。用户上传一次截图后，可选择对应功能进行处理。

## 功能

### 仓库估价

- 使用本地 OCR 读取仓库截图并匹配 WFM 商品目录。
- 对可精确识别且无需额外规格的商品查询 WFM 订单价格。
- 显示游戏内最低卖价、参考价、杜卡德价值及杜卡德/白金建议。

### 核桃分析

- 识别核桃名称和数量，并合并同名结果。
- 结合公开核桃奖励数据和 WFM 价格，提供批量出售、Forma、光辉组和 WFM 出售参考。
- 奖励数据或必要价格缺失时，将结果列入待核对列表。

### 紫卡分析

- 复用上传区的截图进行本地 OCR，识别武器名称和紫卡词条。
- 在线查询武器面板及 Riven 倾向。
- 展示武器分析、词条评分、推荐毕业词条、计算出的属性上限及锁定词条参考。
- OCR 结果可能遗漏或误读内容，用户应核对武器和词条识别结果。

## 数据与隐私

- 截图解码、预处理和 OCR 在浏览器本地完成，完整图片不会上传。
- 仓库估价和核桃分析向 WFM 查询目录或订单；核桃分析还会读取公开奖励数据。
- 紫卡分析会把 OCR 提取出的武器名称候选发送给 WarframeStatus 查询武器资料。
- 商品目录保存在浏览器本地并按缓存期限复用；WFM 请求采用限流、超时、重试和并发去重。

## 安装与开发

开发环境需要 Node.js 20 或更高版本。运行 `npm install` 安装依赖，执行 `npm run build` 后，在 `chrome://extensions` 开启开发者模式并加载 `dist/` 目录。

质量检查命令：

```sh
npm test
npm run lint
npm run build
```

## 已知限制

- OCR 结果依赖截图清晰度、界面语言和名称显示完整度，分析前应人工核对。
- 价格、武器面板和奖励数据依赖网络及第三方数据源。
- 紫卡词条评分和锁定建议基于当前规则及武器数据，属于参考信息。
- 不支持登录、创建订单、自动交易或游戏进程交互。
