# PlatVault V0.1.0

## 版本定位

PlatVault 是一个 Chrome Manifest V3 扩展，用于从 Warframe Prime 物品仓库截图中识别商品，并查询 Warframe.Market 的当前卖单价格。

本版本的目标是缩短“截图后逐个搜索价格”的路径。它提供单次扫描的价格查询和杜卡德/白金建议，不承担库存管理、自动交易或资产汇总。

## 当前功能

- 支持 PNG、JPG、WebP 截图的文件选择、拖拽和 `Ctrl/Cmd + V` 粘贴；可一次加入多张截图。
- 显示每张截图的预览、识别进度和错误状态；可移除单张截图或清空本次扫描。
- 使用扩展内置的简体中文 Tesseract.js Worker 在本地进行 OCR，并对识别到的 Prime 物品按截图网格顺序排列。
- 对常见中文 OCR 片段进行校正，并使用 WFM 商品目录匹配中文、英文名称和 slug。
- 仅对精确匹配且无需额外规格的商品查询价格。无法匹配、模糊匹配或依赖 Rank/变体的商品保留在结果中，但不自动报价。
- 展示商品名称、售价、参考价、杜卡德价值、杜卡德/白金建议，以及中文 WFM 商品页链接。
- 支持按“建议”在杜卡德优先、白金优先和原始截图顺序之间切换。

## 核心流程

```text
添加截图
  → 加载 WFM 商品目录
  → 本地 OCR 与名称匹配
  → 逐个查询可报价商品的订单
  → 展示实时查价结果
```

商品目录加载失败时不会开始识别；单张截图 OCR 失败不会影响其他截图；单个商品订单查询失败会显示错误，但不停止其他商品的查询。用户可继续添加截图，或清空本轮扫描重新开始。

## 业务规则

### 识别与匹配

- 只处理 OCR 文本中包含 `Prime` 的物品名称，过滤仓库界面中的常见噪声文本。
- 模糊匹配仅用于找到候选项；只有匹配分数为 `1` 的精确结果才会查价，避免相近 Prime 部件被错误报价。
- 检测到带 Rank、Arcane、Riven、Lich 或 Sister 等规格需求的商品时，不进行自动报价。

### 价格

价格来自 WFM v2 的可见、`ingame` 状态卖单。

| 字段 | 计算方式 |
| --- | --- |
| 售价 | 有效卖单中的最低白金价 |
| 参考价 | 最低五个有效卖单的中位数；少于三个卖单时取最低价 |
| 杜卡德/白金建议 | `杜卡德 ÷ 售价` 大于或等于 D/P 阈值时建议杜卡德，否则建议白金 |

D/P 阈值默认值为 `8`，可在当前结果页调整。商品缺少杜卡德或有效售价时，不给出建议。订单价格不写入本地缓存，刷新扫描会重新查询。

## 数据、隐私与可靠性

- 截图解码、预处理和 OCR 均在浏览器本地执行。截图仅保留在当前页面会话，移除、清空或关闭页面后释放。
- 扩展仅向 WFM 请求商品目录和订单数据，不访问 Warframe 游戏进程、内存、账号、日志或文件。
- 商品目录使用 `chrome.storage.local` 缓存 24 小时；请求通过统一客户端串行限流。
- 同一商品的并发查询会去重。遇到 429 或服务端错误时最多重试三次，并按响应或指数退避等待。

## 已知限制

- OCR 模型为简体中文，识别效果取决于截图清晰度、界面语言和物品名称显示完整性。
- 不提供人工校正、候选选择、数量识别/合并或总白金估值。
- 不查询买单；“售价”和“参考价”均基于游戏内在线卖单。
- 不支持 WFM 登录、挂单、私聊、交易自动化、历史价格、Riven 估价和带规格物品的自动估价。
- 本文档仅描述仓库估价模块；不包含核桃分析模块。

## 技术说明

- 前端：React、TypeScript、Vite。
- OCR：Tesseract.js Web Worker 和本地语言数据。
- 市场接口：Warframe.Market v2；数据访问集中在 `WfmClient`。
- 质量检查：ESLint、Vitest 和生产构建。

市场数据由 [warframe.market](https://warframe.market/) 提供。PlatVault 是独立第三方工具，与 Digital Extremes 和 warframe.market 无隶属关系。
